# Azimuth FH3 Save Editor 1.0

A self-contained Windows x64 save editor for the Azimuth build of Forza Horizon 3.

- Edit profile properties such as Credits, XP, Level, and skill tokens.
- Browse and edit the embedded SQLite career database.
- Filter and edit BXML SaveState properties and VersionFlags.
- Open a save folder or an individual supported file with any filename.
- Save in place, save to another file/folder, or create a new revision.
- Built-in FH3 crypto, automatic backups, and regenerated commit manifests.
- Automatic backups now use `data\titles\4CE1DFAB\saves_backup`, outside the active saves and revision folders. Automatic save discovery skips this backup folder.
- Remembers file and folder picker locations, while starting empty.
- Improved SaveState tab rendering and scrolling across the editor with buffered grids and stable column widths.

Download `AzimuthFH3SaveEditor.exe` to run directly, or the ZIP for the executable with instructions and notices. No .NET installation or external crypto utility is required.

Close the game before editing and keep a separate backup of your save container.
