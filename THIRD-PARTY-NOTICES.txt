Azimuth FH3 Save Editor 1.0

Built-in FH3 crypto
The editor implements the FH3 profile TFIT/CBC/CMAC format in-process.
Format and round-layout research: Doliman100 / ForzaTech-crypto-tool.
https://github.com/Doliman100/ForzaTech-crypto-tool
The embedded FH3 profile compatibility constants were imported during development
from the legacy FH3 data in the verified ForzaCryptoTool v3.3.5 release by DVS,
which credits Doliman100's work. Only FH3 profile constants are included.
https://github.com/DVS-code/Forza-Crypto-Tool/releases/tag/V3.3.5
No ForzaCryptoTool executable, assembly, console host, or network client is included
or required by this version. No redistribution license is asserted for third-party data.
